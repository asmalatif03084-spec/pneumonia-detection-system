
# AI-Based Pneumonia Detection System

## Project Description
A Computer Vision research project that analyzes
chest X-ray images using Deep Learning.

## Main Features
- Chest X-ray image upload
- Normal and Pneumonia classification
- Prediction confidence score
- Prediction history
- PDF report generation
- Grad-CAM visualization

## Technologies
- Python
- TensorFlow
- OpenCV
- FastAPI
- Next.js
- Supabase
